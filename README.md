# Little Lights

A welcoming, responsive landing page starter for a children’s support organization. It introduces the mission, describes ways a community can help, and gives visitors a simple way to get in touch.

## Run locally

Open `index.html` in a browser. The project is static and does not need a build step or dependencies.

## Make it yours

Little Lights and `hello@littlelights.org` are sample branding and contact details. Replace them throughout `index.html` with the organization’s name and a monitored contact address before publishing. The page currently uses email links only; it does not collect or store visitor information.
